## 1. Executive Summary

`lgen` is an ANSI colorscheme auditor, checker, auto-tuner, and exporter designed for **extreme correctness and yet simple**. It audits terminal color themes written in Markdown (`.md`) against modern color science:
- **Perceptual Contrast**: APCA 0.98G (polarity-aware with black flare compensation) + WCAG 2.1.
- **Uniform Color Space**: Oklab / Oklch with constant-hue chroma reduction (binary search).
- **Accessibility**: Color Vision Deficiency (CVD) simulation via Viénot (1999) matrices to eliminate Git diff Red vs. Green collisions for Protanopia and Deuteranopia.
- **Ergonomics & Semantics**: Background warmth index ($W = b^* + 0.4 a^*$) and chroma anchoring, comment chroma ceiling ($C \le 0.045$), syntax lightness dispersion ($\sigma_L \le 0.070$), monotonicity ($L_{\text{bright}} \ge L_{\text{norm}}$), and background hue camouflage compensation.
- **Workflow & Tooling**: 8-line live syntax code preview box, side-by-side theme diffing (`--diff`), 8 terminal emulator exporters (`--export`), CVD simulation viewport (`--cvd`), interactive watch mode (`--watch`), and in-place markdown auto-fixing (`--fix --write`).

The test suite consists of **59 tests** via `lua tests/all.lua` (100% passing).

## 2. Core Components & Architecture

- [`lgen/color_math.lua`](file:///home/marc/mine/lgen/lgen/color_math.lua):
  - Exact IEC 61966-2-1 piecewise sRGB transfer functions.
  - Oklab & Oklch transforms (Ottosson 2020) and Euclidean $\Delta E_{\text{Ok}}$.
  - constant-hue chroma reduction (`fit_oklch_to_gamut`) preserving the intended hue direction before clipping tolerance and quantization.
  - Hue-adaptive chroma limits (`get_hue_chroma_limits`) using project hue-dependent preferences.
  - APCA 0.98G contrast and WCAG 2.1 contrast formulas.
  - Viénot (1999) sRGB adaptations for Protanopia/Deuteranopia and Brettel (1997) for Tritanopia.
  - Oklab warmth index ($W = b^* + 0.4 a^*$) and temperature classification.
- [`lgen/markdown_parser.lua`](file:///home/marc/mine/lgen/lgen/markdown_parser.lua):
  - Robust parser for Markdown tables (`| Slot | Name | Hex |`), key-value lists (`- name: #hex`), and YAML frontmatter (`strictness`, `name`, `ignore`).
  - Rich alias normalization (maps names like `subtext1`, `overlay2`, `comment`, `bright_red` to ANSI slots 0–15).
- [`lgen/auditor.lua`](file:///home/marc/mine/lgen/lgen/auditor.lua):
  - **Rule A**: Contrast of ANSI 1–7, 9–15 against background (`LOW_CONTRAST`, `SUBOPTIMAL_CONTRAST`).
  - **Rule B**: Comment contrast & ergonomics (`COMMENT_ILLEGIBLE`, `COMMENT_FAINT`, `COMMENT_OVERLY_SATURATED`, `COMMENT_TEMPERATURE_MISMATCH`).
  - **Rule C**: Monotonicity (`INVERTED_BRIGHT_PAIR`).
  - **Rule D**: Syntax token collision (`SYNTAX_COLLISION`, `SYNTAX_AMBIGUITY`).
  - **Rule E**: Git diff Red vs. Green discriminability under CVD (`CVD_DIFF_COLLISION`, `CVD_DIFF_DIFFICULT`).
  - **Rule F**: Hue sector fidelity (`HUE_SECTOR_MISMATCH`).
  - **Rule G**: Cursor & selection contrast (`CURSOR_LOW_CONTRAST`, `SELECTION_LOW_CONTRAST`).
  - **Rule H**: Background temperature and chroma anchoring (`BACKGROUND_TOO_COLD`, `BACKGROUND_TOO_WARM`, `BACKGROUND_OVER_SATURATED`, `TEMPERATURE_CLASH`).
  - **Rule I**: Hue-adaptive vibrancy check with 5% hysteresis (`MUTED_COLOR`).
  - **Rule J**: Inter-accent lightness dispersion across syntax tokens 1–6 (`ACCENT_LIGHTNESS_IMBALANCE`).
  - **Rule K**: Tinted background hue camouflage detection (`ACCENT_BACKGROUND_CAMOUFLAGE`).
- [`lgen/fixer.lua`](file:///home/marc/mine/lgen/lgen/fixer.lua):
  - Gamut-aware contrast adjuster (`adjust_contrast`).
  - CVD pair separator (`adjust_cvd_pair`).
  - Temperature re-anchor (`anchor_temperature`).
  - Non-neon vibrancy booster (`boost_vibrancy`).
  - Comment desaturator & tint aligner (`desaturate_comment`).
  - Syntax lightness balancer (`balance_accent_lightness`).
- [`lgen/exporter.lua`](file:///home/marc/mine/lgen/lgen/exporter.lua):
  - Exports themes to `alacritty` (TOML), `kitty` (conf), `ghostty` (config), `wezterm` (lua), `nvim` (lua table), `foot` (ini), `xresources` (X11), and `windows_terminal` (JSON).
- [`lgen/reporter.lua`](file:///home/marc/mine/lgen/lgen/reporter.lua):
  - Truecolor ANSI terminal report generator with swatches and metric tables.
  - Live 8-line syntax & Git diff code preview box (`render_syntax_preview`).
  - Side-by-side theme comparison diff (`format_diff`).
  - JSON exporter (`format_json`) and Markdown report generator (`format_markdown`).
  - In-place Markdown patcher (`apply_fixes_to_markdown`).
- [`lgen/init.lua`](file:///home/marc/mine/lgen/lgen/init.lua):
  - Public module API (`audit_file`, `audit_string`, `audit_palette`, `export_file`, `diff_files`).
- [`bin/lgen`](file:///home/marc/mine/lgen/bin/lgen):
  - Executable CLI supporting all options (`--strict`, `--relaxed`, `--vibrant`, `--preview`, `--no-preview`, `--diff`, `--export`, `--cvd`, `--watch`, `--fix`, `--write`, `--json`, `--md`).
