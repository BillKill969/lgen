# Problematic Dark Theme

This theme exhibits common colorscheme pitfalls:
1. Low contrast dark blue (ANSI 4)
2. Illegible comment gray (ANSI 8)
3. Inverted bright red (ANSI 9 is darker than ANSI 1)
4. Red/Green Git diff collision under red-green colorblindness
